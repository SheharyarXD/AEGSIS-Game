Known limits

  • Collapse uses four moving source masses and authored ruin variants, with three approximate convex collision hulls per ruin. It is an artistic structural system.
  • Shared-buffer facade remnants preserve source UVs and materials; small pooled debris sleeps or becomes static. Individual decorative triangles do not all receive collision.
  • Broad avenues, repeating source families, simplified traffic/crowds and some breach/interior surfaces still need art direction. This report does not claim premium visual completion.
  • Rain, smoke, flames and wet reflections are optimized shader approximations. Higher tiers increase shadows/detail/effects and allow higher pixel-ratio caps on high-DPI displays. The measured DPR-1 display keeps MEDIUM/HIGH/ULTRA at 1280 x 720; LOW is 1088 x 612.
  • FPS, p95/p99 and worst frames are scene samples rather than a guarantee for every location or driver. GPU memory snapshots are post-timing point samples, not peak VRAM.
  • The 18 October shared-GPU runs included a large Android emulator allocation. Current per-scene hardware snapshots establish whether that contender was present; cross-day FPS differences are not a controlled performance attribution.
  • Existing noncommercial pilot placeholder licensing remains unchanged; see the project README and pilot manifest before public or monetized distribution.
